# BArt1st's Personal Website

Personal academic website maintained by [BArt1st](https://github.com/BArt1st).

[Visit the website](https://bart1st.github.io/)

## Maintainer

- [BArt1st](https://github.com/BArt1st)

## Editing the website

- `_config.yml`: site settings.
- `_pages/`: website pages.
- `_news/`: announcements.
- `_bibliography/papers.bib`: publications.
- `assets/`: images, PDFs, and other static files.

See [INSTALL.md](INSTALL.md) for local setup and [CUSTOMIZE.md](CUSTOMIZE.md) for theme customization.
